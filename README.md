# Medical-Dataset-Insight

  OBJECTIVE-
This project focuses on cleaning, transforming, and analyzing a synthetic medical appointments dataset using SQL.
My goal was to demonsatrare data cleaning, data standardization, analytical thinking, and SQL query skills.
The project reflects real world tasks such as handeling messy data, standardizing inconsistent values, creating new calculated fields, and generating meaningful insight.
---

### PROJECT OVERVIEW-
The dataset contains medical appointment records, including:
- Patient information
- Appointment date & statuses
- Department & doctor details
- Billing and payment information
- Insurance provider
The original dataset contained multiple incosistencies, formatting issues, and messy text fields.
---

### DATA CLEANING:
- Standardized text fields
- Removed titles and credentials
- Cleaned phone numbers
- Standardized appointment statuses
- Corrected any typos and normalized provider names
- Renamed columns
- Added new calculated fields
---

### KEY INSIGHT
- The dataset includes 350 unique patients, providing a solid base for analysis.
- Appointment efficiency is impacted by a 22.29% no show rate
- The clinic generated $81.4k in total revenue, with Cardiology contributing the most.
- Outstanding balance total $8.8K, largely driven by patients without insurance
- Aetna, Medicare, and BlueCross are the most common insurance providers.
